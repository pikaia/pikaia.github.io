Coney Island in New York had a switchback railway, a Ferris wheel and a million visitors on a hot Sunday. Coney Island in Singapore has a locked gate, a gravel track and a sign asking cyclists to slow down for wildlife. The name travelled here in 1950, attached to a small island off Punggol that a businessman had just bought and meant to turn into a seaside playground. That plan failed, as did the ones before and after it. What finally opened to the public in 2015 was close to the opposite of a resort, and that was the point.

      styleEl.textContent += '@keyframes kb' + i + ' { 0% { transform: scale(' + s.zoom[0] + '); background-position: ' + s.pan[0] + '; } 50% { transform: scale(' + s.zoom[1] + '); background-position: ' + s.pan[1] + '; } 100% { transform: scale(' + s.zoom[2] + '); background-position: ' + s.pan[2] + '; } }\n';
    }
    stage.appendChild(el);
    return el;
  });
  slides.forEach(function (s) { if (s.src) { var img = new Image(); img.src = s.src; } });

  var currentIndex = -1, currentSentenceIndex = -1;
  function fmtTime(t) {
    if (!isFinite(t)) return '0:00';
    var m = Math.floor(t / 60), s = Math.floor(t % 60);
    return m + ':' + (s < 10 ? '0' : '') + s;
  }
  function slideIndexForTime(t) {
    var idx = 0;
    for (var i = 0; i < imageSchedule.length; i++) { if (imageSchedule[i].t <= t) idx = imageSchedule[i].slide; else break; }
    return idx;
  }
  function sentenceIndexForTime(t) {
    var idx = 0;
    for (var i = 0; i < captionChunks.length; i++) { if (captionChunks[i].offset_s <= t) idx = i; else break; }
    return idx;
  }
  function updateForTime(t) {
    var sIdx = slideIndexForTime(t);
    if (sIdx !== currentIndex) {
      if (currentIndex >= 0) slideEls[currentIndex].style.opacity = '0';
      slideEls[sIdx].style.opacity = '1';
      currentIndex = sIdx;
    }
    if (slideEls[sIdx]._chartUpdate) {
      var schedIdx = imageSchedule.findIndex(function (e) { return e.slide === sIdx; });
      var segStart = imageSchedule[schedIdx].t;
      var nextEntry = imageSchedule[schedIdx + 1];
      var segEnd = nextEntry ? nextEntry.t : TOTAL_DURATION;
      var chartProgress = Math.min(1, Math.max(0, (t - segStart) / Math.max(0.001, segEnd - segStart)));
      slideEls[sIdx]._chartUpdate(t, chartProgress);
    }
    var cIdx = sentenceIndexForTime(t);
    if (cIdx !== currentSentenceIndex) { captionEl.textContent = captionChunks[cIdx].text; currentSentenceIndex = cIdx; }
    var pct = Math.min(100, (t / TOTAL_DURATION) * 100);
    progressFill.style.width = pct + '%';
    timeEl.textContent = fmtTime(t) + ' / ' + fmtTime(TOTAL_DURATION);
  }
  function openViewer() {
    viewer.style.display = 'block';
    currentIndex = -1; currentSentenceIndex = -1;
    slideEls.forEach(function (el) { el.style.opacity = '0'; });
    watchAudio.currentTime = 0;
    updateForTime(0);
    watchAudio.play();
  }
  function closeViewer() { viewer.style.display = 'none'; watchAudio.pause(); }

  watchWidget.addEventListener('click', openViewer);
  watchWidget.addEventListener('keydown', function (e) { if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); openViewer(); } });
  closeBtn.addEventListener('click', closeViewer);
  playBtn.addEventListener('click', function () { if (watchAudio.paused) watchAudio.play(); else watchAudio.pause(); });
  watchAudio.addEventListener('play', function () { playBtn.innerHTML = '&#10074;&#10074;'; });
  watchAudio.addEventListener('pause', function () { playBtn.innerHTML = '&#9654;'; });
  watchAudio.addEventListener('timeupdate', function () { updateForTime(watchAudio.currentTime); });
  watchAudio.addEventListener('ended', closeViewer);
  progress.addEventListener('click', function (e) {
    var rect = progress.getBoundingClientRect();
    var pct = (e.clientX - rect.left) / rect.width;
    watchAudio.currentTime = pct * TOTAL_DURATION;
  });
})();
</script>

## From Pulau Serangoon to a rich man's beach

<div style="float: left; max-width: 270px; margin: 0.3em 1.5em 1em 0;">
  <img src="https://upload.wikimedia.org/wikipedia/commons/f/f9/Hu_Wenhu2.jpg" alt="Bust portrait of Aw Boon Haw in a suit and tie, captioned Aw Boon-haw (Hu Wen-hu)">
  <em>Aw Boon Haw, from the 1931 directory Who's Who in China. Public domain, via <a href="https://commons.wikimedia.org/wiki/File:Hu_Wenhu2.jpg">Wikimedia Commons</a>.</em>
</div>

The island's older name is Pulau Serangoon, and for most of its history it was a thin, wooded strip of land off the Punggol coast with nothing much on it. That changed in 1937, when Aw Boon Haw bought it. He and his brother Aw Boon Par had built the Tiger Balm fortune, and Aw Boon Haw put a beach villa on the island: a single-storey house of about 600 square metres in the modern style of the day, with a central hall, an open verandah running around it and its own well for fresh water. The design is usually attributed to Ho Kwong Yew, one of the architects then bringing a plainer, flat-roofed look to Singapore. Locals stopped calling the place Pulau Serangoon and started calling it Haw Par Island.

The villa did not last long as a retreat. The Japanese Occupation damaged it along with much of the Aw family's property, and after the war Aw Boon Haw sold the island on.

## The resort that never came

![Illuminated towers and arches of Luna Park at Coney Island, New York, photographed at night around 1905](https://upload.wikimedia.org/wikipedia/commons/8/82/Night_in_Luna_Park%2C_Coney_Island_%281905%29.jpg)

*Luna Park, Coney Island, New York, around 1905 — the amusement district the Singapore island was named after. Photograph by the Detroit Publishing Co.; Library of Congress, public domain, via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Night_in_Luna_Park,_Coney_Island_(1905).jpg).*

The buyer, in 1950, was a local businessman named Ghulam Mahmood. He paid around $100,000 and announced that he would remake the island as a holiday resort for ordinary working families: swimming, boating and fishing, a skating rink, a dance hall, a restaurant and bar, and a handful of cottages for honeymooners. He renamed it Coney Island, after the New York amusement district, and advertised it as Singapore's first island health resort. For a while it ran, with launches crossing every half hour and a house band billed as the Coney Island Band.

It did not take. Within about three years the island was up for auction. A succession of owners followed, none of whom found a way to make the resort idea work, and by the early 1970s the island belonged to a businessman from Thailand who was trying, without success, to sell it for a million dollars.

A group of us went out to the island once during our national service, around 1979. It was well before any of this was a park, or even a name most people knew. The place was overgrown and completely quiet, with a low building coming apart among the trees and a beach full of driftwood. Nobody stopped us, because there was nobody there to stop us.

![A group of young men on a beach, four standing and three kneeling, with the word "UNITY" set out vertically in the sand beside them; a sepia print from 1979](/assets/images/coney-island-1979.jpg)

*Group of friends on the island, 1979. From Paul Kang's collection.*

## The state takes over

The government acquired Coney Island in 1972. Two years later the Port of Singapore Authority began a reclamation project costing about $20 million, which enlarged the small original island several times over and built a bridge across to the mainland. A second round of filling came in the 1990s, this time as part of Punggol new town, and it closed most of the water between the island and Punggol, leaving a channel only about a hundred metres wide. There had been a proposal in the 1980s to close that last gap as well and fold the island into the mainland outright. It was dropped after objections that joining it on would take away the very thing that made it worth keeping.

For most of these decades the island was simply shut. It was fenced off, absent from the bus map, used for grazing cattle and for little else.

## A park that refuses to be a resort

<div style="float: left; max-width: 280px; margin: 0 1.5em 1em 0;">
  <img src="https://upload.wikimedia.org/wikipedia/commons/b/bd/Pair_of_Smooth-coated_otters.jpg" alt="Two smooth-coated otters on the rocky edge of the Coney Island west causeway">
  <em>Smooth-coated otters at the Coney Island west causeway, 2024. Photo by Jnzl's Photos, <a href="https://creativecommons.org/licenses/by/2.0/">CC BY 2.0</a>, via <a href="https://commons.wikimedia.org/wiki/File:Pair_of_Smooth-coated_otters.jpg">Wikimedia Commons</a>.</em>
</div>

Coney Island Park opened on 10 October 2015, run by the National Parks Board, at about 50 hectares. The design is deliberately spare. There are five short stretches of beach, labelled A to E, a gravel spine a little over two kilometres long, and boardwalks over the wetter ground. There is almost nothing to buy, the toilets compost rather than flush, and the lighting is kept low. Much of the tree cover is casuarina, some of it self-sown from seed carried in by birds, and about eighty bird species have been recorded on the island.

In the park's first year a single Brahman bull, thought to be a leftover from the cattle that once grazed there, wandered the tracks and drew a small following of photographers. It died in October 2016, during a health check, and the BBC gave it an obituary headlined "the life and death of a lonely Singapore cow." The Haw Par villa is still standing, roofless and fenced off, back among the trees near the shore. The otters, the wild pigs and the birds arrived on their own.

The irony is not hidden. For sixty years people tried to sell this island as somewhere to have fun, as a beach club, a fairground, a honeymoon spot, and none of it held. The version that finally worked is the one that asks nothing of visitors and sells them nothing at all.

<div style="clear: both;"></div>

**Where it fits in the bigger story:** A fair amount of what looks like leftover nature in Singapore is nothing of the kind. Coney Island is larger than it was born, tied to the shore by reclaimed land, planted up, and presented as wilderness in large part because the earlier and more commercial ideas for it fell through. The rough edges are a decision, not an accident.
